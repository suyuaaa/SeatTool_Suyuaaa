## 项目名称：SeatTool

- ### 功能特性
  - 一个调座位的小工具，可以用于多种环境，譬如班级调座位
  - 界面简洁，工能完善，具有添加班级、删除班级、修改班级、调座位、记忆化存储和教程功能
  - 能自定义学生属性，禁用多个被指定的学生不会相邻
  - 有记忆化功能，并使用退火算法，保证结果随机且在可能的情况下，与前五次结果不重复
  - 本项目由**pyQt5**移植而来
- ### 使用说明

  - #### 1.准备工作

  - 下载项目到本地
  - 解压**zip文件**
  - 打开**微信开发者工具**等软件将解压结果（文件夹）导入项目
  - 运行，建议使用**稳定版本**的API

- ### 算法原理简介

1. **初始化**：将所有学生随机放置在可用座位上（避开占用坐标与讲台区域）。
2. **DH 冲突修复**：检查每个学生的八邻域，若存在同 DH 组学生，则移动到另一个不冲突的空位。
3. **模拟退火优化**：定义目标函数为“每个学生与其邻居的爱说话程度之差的平方和”。通过随机交换座位，以一定概率接受使目标函数增大的移动（温度逐渐降低），最终找到较优解。
4. **历史检查**：若新方案与历史方案的平均相似度 > 90%，则更换随机种子重新生成。
